# AtlasVanguard

Website for the AtlasVanguard gaming clan (Valorant, CS2, Call of Duty Mobile,
Free Fire, PUBG Mobile, Rainbow Six Siege).

Live site: https://atlasvanguard-bvwax1.freebuff.site

## What each file is

- `index.html` - the whole page (hero, game cards, how to join, rules, footer)
- `styles.css` - colours, layout, animations
- `main.js` - sets the Discord invite and Instagram links, nav and scroll effects
- `assets/logo.png` - the round clan logo (also the browser tab icon)
- `assets/bg-art.jpg` - the dimmed painting used as the page background
- `assets/emblem.jpg` - an older emblem image, kept but not used
- `robots.txt` / `sitemap.xml` - files that help search engines find the site

## Making changes

Edit the files here, or ask the assistant to change the live site - it can refresh
this copy afterwards.

## Hosting on GitHub Pages (optional)

Repo Settings -> Pages -> Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
The page then appears at https://sahoosoumyadarsil-droid.github.io/atlasvanguard/
